# Context Researcher File

ค้นหาคำหรือประโยคในเอกสาร **PDF · Excel · Word · CSV/TXT** ภายในโฟลเดอร์ที่ระบุ — สำหรับ Windows desktop (Flutter)

- พิมพ์คำค้น → เลือกโฟลเดอร์/ไฟล์ → เห็นรายการไฟล์ที่มีคำนั้น พร้อมจำนวนจุดที่พบ
- กด chip (`หน้า 4` · `Sheet1!B12` · `บรรทัด 88`) = เปิด preview แล้วเด้งไปจุดนั้นพร้อม highlight
- สร้าง **โปรเจค** ผูกโฟลเดอร์งานไว้ (เช่น RMA) → เปิดโปรแกรมมาค้นได้ทันที เพราะ index เก็บไว้ใน SQLite
- โหมด **ค้นแบบไม่ผูกโปรเจค** = อ่านไฟล์สด ไม่เก็บ index
- ค้นภาษาไทยกลางคำได้ (FTS5 trigram)

> ระบบนี้ **อ่านไฟล์อย่างเดียว** ไม่แก้/ย้าย/ลบเอกสารของผู้ใช้ และไม่ส่งข้อมูลออกเครือข่าย

## เริ่มใช้
ต้องมี Flutter ≥ 3.47.0

```bash
flutter pub get
```

```bash
flutter run -d windows
```

เอกสารอื่น: `CLAUDE.md` (กฎการทำงาน) · `SKILL.md` (วิธีทำงานร่วมกัน) · `HANDOFF.md` (สถานะ + FILE MAP + ข้อจำกัด)
